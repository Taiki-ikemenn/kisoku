# 規則を守れ! / 規則を守って1Fに着け!  (v2.0.0)

10Fから階段を降りて、1Fの出口を目指すルール遵守ゲーム。階ごとに規則がランダムに決まる（全100種類）。

- 単一HTML（`index.html`）。GitHub Pagesでそのまま遊べる
- 操作：タップ移動 / ジョイスティック / 方向ボタン / コントローラー / キーボード（設定で切り替え）
- 設定：操作方法、ジョイスティックの左右位置、効果音ごとのON/OFFと音量、アニメーション控えめ
- 各階は「規則を守って降りられる経路がある」ことを確認してから出している
- 「続きから」：途中の階から再開できる（ブラウザに自動保存）
- 規則カードをタップすると、アイコン付きのくわしい説明が出る（ゲーム中の一覧・規則を見る・各階の確認画面）
